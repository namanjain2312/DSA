Kosaraju's Algorithm
Strongly Connected Component (SCC) -  is a subset of vertices where every vertex in the subset
is reachable from every other vertex in the same subset by traversing the directed edges.

Kosaraju's Algorithm - Helps us to find the strongly connected nodes (SCC) in a graph in a Directed Graph

Intution : If i do a dfs from backend then i will be able to find the same

If graph not directed make it directed graph

Take Example of Graph
1 - 2
2 - 4 , 3
3 - 1
4 - 5

Now in this above graph if i do traversal from 5 instead of 2 then do dfs on 4 and then on 1 or 3
then i will be able to get all the strongly connected componenets

So basically it has 3 steps in this algorithm
1.Sort all the nodes in order of finishing time (Which is basically do a topological sort)
2.Transpose the graph (Basically reverse all the Edges)
    a.Advantage of doing the above step is that once you reverse the edge , you will not be able to
    go anywhere other than SCC
3.Do DFS according to the finishing time

Time Complexity
1.Topological Sort - O(V+E)
2.DFS - O(V+E)

Space Complexity
1.Transpose Graph - O(V+E)
2.Vis - O(V)
3.Stack - O(V)

class Solution {
  public:

    void dfs(int curr,stack<int>&s,vector<int>&vis,vector<vector<int>> &adj)
    {
        if(vis[curr]==1)
            return ;

        vis[curr]=1;

        for(int i=0;i<adj[curr].size();i++)
            dfs(adj[curr][i],s,vis,adj);

        s.push(curr);

    }

    int dfs2(int curr,vector<int>&vis,vector<vector<int>> &transpose)
    {
        if(vis[curr]==1)
            return 0;


        vis[curr]=1;

        for(int i=0;i<transpose[curr].size();i++)
            dfs2(transpose[curr][i],vis,transpose);

        return 1;
    }

    int kosaraju(vector<vector<int>> &adj) {
        int n=adj.size();
        int out=0;
        stack<int> s;
        vector<vector<int>> transpose(n,vector<int>());
        vector<int>vis(n,0);

        for(int i=0;i<n;i++)
            dfs(i,s,vis,adj);

        for(int i=0;i<n;i++)
        {
            for(int j=0;j<adj[i].size();j++)
            {
                transpose[adj[i][j]].push_back(i);
            }
        }



        for(int i=0;i<n;i++)
            vis[i]=0;

        while(!s.empty())
        {
            out=out+dfs2(s.top(),vis,transpose);
            s.pop();
        }
        return out;
    }
};
