16.FloydWarshallAlgorithm

FloydWarshall Algo
1>Works for directed graph and we will use adj matrix in it
2>If undirected graph given then convert it in directed graph
3>MutliSource Shortest Path Algo
4>So basically from every node we have to find the shortest path to every other node for a node
5>It also helps to detect the negative cycle as well


Steps
1>Go Via Every Node/Vertex in order to reach the answer
    d[i][j] = min(d[i][k]+d[k][j])
    So DP
2>To detect negative cycle if Cost[i][j] where i==j is not zero and <0 then its have negative cycle as well
3>Because in negative cycle node -> same node costing will become <0 evetually after all the operation
which is ideally wrong , and thus negative cycle

Time Complexity - O(n^3)
Space Complexity - O(n^2))

//Instead of -1 do INT_MAX;


class Solution {
  public:
    void shortestDistance(vector<vector<int>>& mat) {

        int n=mat.size();

        for(int via=0;via<n;via++)
        {
            for(int i=0;i<n;i++)
            {
                for(int j=0;j<n;j++)
                {
                    if (mat[i][via] != -1 && mat[via][j] != -1)
                    {
                        // If no direct path exists from i to j, update it
                        if (mat[i][j] == -1)
                            mat[i][j] = mat[i][via] + mat[via][j];
                        else
                            mat[i][j] = min(mat[i][j], mat[i][via] + mat[via][j]);
                    }
                }
            }
        }

        return ;
    }
};
