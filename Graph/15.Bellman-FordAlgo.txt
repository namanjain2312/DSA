Bellman-Ford Algo
1>Algo to find the shortest path itself
2>Works for directed graph only
3>If graph is  undirected graph then convert in directed graph and then apply algo
4>Works for non connected graph also
5>Works for path weight < 0 and negative cycle also

Steps
1>Relax all the edges n-1 times sequentially
2>if(dist[u]+wt < dist[v])
    dist[v]=dist[u]+wt;
3>dist/vis array (with INT_MAX intialization)

Other Thinkings
1>Why only n-1 iteration , consider graph 1->2->3->4->5
2>If there is negative cycle then after doing one more iteration after n-1 iteration , for some node in
dist array would still reduce

TimeComplexity
1>O(V * E)

Space Complexity
1>O(V)

class Solution {
  public:
    vector<int> bellmanFord(int V, vector<vector<int>>& edges, int src)
    {
        vector<int>vis(V,100000000);
        int n=0;//taken 0 here
        int start,end,dist;

        vis[src]=0;

        while(n<=V-1)
        {
            for(int i=0;i<edges.size();i++)
            {
                start=edges[i][0];
                end=edges[i][1];
                dist=edges[i][2];
                if(((vis[start]+dist)<vis[end])&&vis[start]!=100000000)
                {
                    if(n==V-1)//it will the nth iteration
                        return vector<int>{-1};

                    vis[end]=vis[start]+dist;
                }
            }
            n++;
        }

        return vis;
    }
};
