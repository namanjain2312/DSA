MST using Prim's Algo
Spanning Tree - A tree in which we have n nodes and n-1 edges and all nodes are reachable from
each otherMST - Among all the Spanning Tree trees having Minimum sum of wights is the MST

A spanning tree is defined as a tree-like subgraph of a connected, undirected graph that includes all
the vertices of the graph. Or, to say in Layman’s words, it is a subset of the edges of the graph
that forms a tree (acyclic) where every node of the graph is a part of the tree.

The minimum spanning tree has all the properties of a spanning tree with an added constraint of having
the minimum possible weights among all possible spanning trees. Like a spanning tree, there can also
be many possible MSTs for a graph.

Steps

2>We can start with any vis node

class Solution {
  public:
    // Function to find sum of weights of edges of the Minimum Spanning Tree.

    struct comp{
        bool operator()(const vector<int>v1,vector<int>v2){
            return v1[0]>v2[0];
        }
    };

    int spanningTree(int V, vector<vector<int>> adj[])
    {
        int weight =0;
        priority_queue<vector<int>,vector<vector<int>>,comp> pq; //dist , currNode, parent
        vector<int>vis(V,0);
        int curr,dist,parent;


        pq.push({0,0,-1});

        while(!pq.empty())
        {
            dist=pq.top()[0];
            curr=pq.top()[1];
            parent=pq.top()[2];

            pq.pop();

            if(vis[curr]==1)
                continue;

            vis[curr]=1;
            weight=weight+dist;


            for(int i=0;i<adj[curr].size();i++)
            {
                pq.push({adj[curr][i][1],adj[curr][i][0],curr});
            }

        }
        return weight;
    }
};
